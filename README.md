# Art That Moves Me

Art That Moves Me is a gentle exercise tracker that turns everyday movement into a mystery-art reveal.

Complete a walk, stretch, wall sit, or any movement you choose. Each completed task earns XP and uncovers several tiles from a public-domain masterpiece. Finish the artwork to unlock its title, artist, history, and a museum-guide-style story.

**[Open Art That Moves Me](https://9yqc29sr9y-alt.github.io/art-that-moves-me/)**

## How it works

- Add your own movement tasks or use the quick-add suggestions.
- Check off a task to earn XP and reveal artwork tiles.
- Unlock clues at 20%, 40%, 60%, and 80%.
- Complete the mosaic to receive the artwork's story and a detail to examine more closely.
- Save finished masterpieces to your gallery.
- Spend earned XP on personal, real-life rewards.
- Use **Undo last** to correct an accidental completion.
- Use **Reset today** to clear today's progress and cover the current artwork again.

The first artwork contains 40 tiles. Each new mystery becomes a little more detailed.

## The philosophy

Art That Moves Me is designed around curiosity instead of guilt. Missing a day does not kill, damage, or remove anything. The artwork simply waits for you to return.

The goal is not perfect performance. It is to make something beautiful by showing up.

## Privacy and saved progress

Art That Moves Me has no account system, analytics, advertisements, or database. Progress is saved in your browser using `localStorage`.

This means:

- Your exercise progress remains on your device.
- Different browsers and devices have separate progress.
- Private browsing will not save progress reliably.
- Clearing browser or website data can erase progress.
- Updating the website at the same address should preserve existing progress.

## Install on a phone

Open the live website in your phone's browser, then:

- **iPhone/Safari:** tap Share, then **Add to Home Screen**.
- **Android/Chrome:** open the menu, then select **Add to Home screen** or **Install app**.

## Updating the website

The app is intentionally contained in one file: `index.html`.

To publish an update through GitHub:

1. Replace the existing `index.html` with the updated file.
2. Commit the change to the `main` branch.
3. Wait a minute or two for GitHub Pages to redeploy.
4. Refresh the live website.

For frequent updates, GitHub Desktop provides the easiest workflow: replace the file, commit to `main`, and push to GitHub.

## Technology

Art That Moves Me uses plain HTML, CSS, and JavaScript. It has no build process, framework, package installation, or paid hosting requirement.

## Status

Art That Moves Me is an evolving personal project. Planned possibilities include progress export/import, a larger artwork collection, cloud sync, and a browsable completed-art gallery.
